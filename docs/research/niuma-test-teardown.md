## 2. 这个测评是什么

| 项目 | 内容 |
|---|---|
| 名称 | 职场苦劳值深度检测（页首标签：工作性价比计算器；结果页标题：职场性价比报告） |
| 定位 | 娱乐向互动工具。页脚自述："仅供娱乐，请勿将测试结果发送给老板"；介绍文案："用科学（且扎心）的算法，算出你的真实时薪与职场苦劳值" |
| 完成时长 | 页面标注"约 1 分钟" |
| 题量 | 非传统量表。3 步流程共 14 个输入项（Step1 生存数据 6 项 / Step2 环境与成长 4 项 / Step3 个人基本盘 3 项 + 最后生成报告） |
| 题型 | **无李克特量表、无迫选题**。混合表单式输入：数值输入（月薪/工时/通勤）、滑杆（摸鱼时长 0–8h）、单选（3–5 个带 emoji 的情境选项）、多选（福利清单） |
| 维度框架 | 3 层 × 内部 5 维。输入层分"生存数据 / 环境与成长 / 个人基本盘"三轨；输出层雷达图五维：薪酬购买力、时间掌控权、情绪健康度、简历含金量、技能成长率 |
| 理论基础 | **无心理学构念基础**。无任何人格/动机量表理论引用。全部是产品经理式加权规则：乘法调节因子 + 分段阈值 + 规则覆盖（override） |

**关键定性：** 它测的不是"人"，是"岗位的投入产出比"（钱/工时/环境/资历的加权）。人格、动机类构念在本测试中完全缺席——这决定了我们对它的定位：可借鉴的是**交互设计与结果呈现手法**，不是测评科学。

## 3. 题目设计手法抽样（全量 14 项，含原文）

### Step 1 生存数据录入（客观数值，不做心理测量）

1. **所在城市等级**（单选 5 项）：北上广深 / 新一线·二线 / 三线及其他 / 🌐 海外·跨国 —— 纯分类变量。
2. **税前月薪（元）**（数值输入，placeholder："别不好意思写，没人看"）—— 注意其用幽默弱化作答压力。
3. **发薪月数 / 额外年终奖**（数值输入，默认 12 / 0）。
4. **月工作天数**（单选 3 项）：双休（21.75 天）/ 大小周（24 天）/ 单休（26 天）—— 选项自带换算值，降低认知负担。
5. **日均工时 / 通勤往返**（数值输入，副文案"含隐形加班"、"含等车发呆"）—— 用副文案界定测量口径。
6. **日均摸鱼时长**（滑杆 0–8h，两端锚点"0h 劳模 ↔ 8h 薪水小偷"）—— 滑杆 + 锚点标签。

### Step 2 环境与成长评估（情境单选，**本题型是本报告的核心借鉴点**）

7. **你的直属领导…**（单选 3 项，各带 emoji + 具体行为描述）：
   - 👹 PUA大师/听不懂人话/朝令夕改
   - 😐 普通工具人，无功无过
   - 😇 情绪稳定，愿意教东西，偶尔请客

8. **下班后的微信群…**（单选 3 项）：
   - 📢 24小时待命
   - 📱 偶尔有事
   - 🔕 几乎失联

9. **福利与环境（多选）**：
   - 厕所自由（带薪拉屎不计时）
   - 有零食/下午茶/健身房
   - 大小周/调休克扣/打卡严苛

10. **这份工作的成长性…**（单选 3 项）：
    - 🛑 重复性劳动/学不到东西
    - 🔄 偶尔有新挑战/按部就班
    - 🚀 核心项目/技能飞速提升

### Step 3 个人基本盘评估（自我定位单选，**情境锚定程度最高**）

11. **当前阶段**（单选 4 项）：刚出村的新手（应届-1年）/ 熟练工（1-3年）/ 职场老鸟（3-5年）/ 老油条（5年以上）。
12. **学历光环**（单选 4 项）：实用至上（大专及以下）/ 标准配置（普通本科）/ 学历加持（硕士及以上/海归）/ 顶级buff（C9/985名校）—— 把学历换算成"游戏 buff"语言。
13. **核心护城河（不可替代性/议价权）**（单选 3 项，**全文最具代表性的题目**）：
    - 🔌 **A. 随插随用的 U 盘（极易替代）**："纯执行层。老板今天开掉我，明天招个大学生培训三天就能完美接我的班。"
    - 🧱 **B. 承上启下的承重墙（有一定壁垒）**："熟练掌握业务流程或部分客户资源。我走了，公司短期内运转会很难受，交接至少得一个月。"
    - 👑 **C. 掌握命脉的核心大爹（不可替代）**："掌握核心技术代码/独家大客户/卡脖子资源。我敢掀桌子，因为我走了这块业务得塌半边天。"

### 题目手法分析

- **测什么**：Step 2/3 测的是"用户对自己处境的主观分类"，不是心理特质。每个题项测一个单一构面（领导质量、边界感、福利、成长性、资历、学历、可替代性）。
- **怎么问**：**情境锚定式（behaviorally anchored）**——选项不是抽象形容词（如"领导很好"），而是给一段可对号入座的具体情境描述 + 第一人称内心独白（如"我敢掀桌子"）。这是全测试最值得借鉴的手法：降低作答者自我认知门槛，同时用第一人称口吻降低防御。
- **题型共性**：无迫选题、无李克特；单选选项数量 3–5 个，全部带 emoji 作视觉锚点；每个选项背后直接挂一个数值/权重（0.8–1.2），用户选完即完成量化——**选项即数据**。
- **反例（不可学）**：选项文字自带价值判断（"😐 普通工具人"vs"😇 情绪稳定愿意教东西"），把"正确选项"写在脸上，存在明显引导性。

## 4. 评分模型（源码级还原）

```js
// 1) 基础时薪
等效月薪 = (月薪 × 发薪月数 + 年终奖) / 12
baseRate = 等效月薪 / (月工作天数 × (日均工时 + 通勤))

// 2) 环境调节（乘法因子）
bossMod ∈ {0.8, 1.0, 1.2}   msgMod ∈ {0.9, 1.0, 1.1}
envMod = 1.0 + 0.05×厕所自由 + 0.05×下午茶 - 0.1×打卡严苛
growthMod ∈ {0.9, 1.0, 1.2}

// 3) 个人基本盘（三个因子相乘）
personalMod = stageMod × eduMod × moatMod
// stageMod: 新手0.85/熟练1.0/老鸟1.1/老油条1.2
// eduMod:   大专0.9/本科1.0/硕士1.08/名校1.15
// moatMod:  U盘0.9/承重墙1.0/大爹1.15

// 4) 最终时薪
finalRate = baseRate × bossMod × msgMod × envMod × growthMod × personalMod × (1 + 摸鱼时长/工时 × 0.5)
```

- 输出五维雷达分：薪酬购买力（月薪区间+城市修正）、时间掌控权（10−(工时+通勤−8)）、情绪健康度（=环境分）、简历含金量（=personalMod 映射）、技能成长率（=growthMod 映射），各 clamp 到 1–10。
- 结果标签：按时薪阈值分 6 档（见下节）+ 4 条"暴击覆盖规则"优先于基础档。
- **方法论定性**：这是典型的**加权线性模型 + 规则引擎**，每个输入都对最终分数有可计算的显式贡献（可完全回溯）。但没有信度、效度、常模，无任何统计学依据；精确到 0.1 元的"真实时薪"属于**虚假精确**。

## 5. 结果呈现

1. **核心数字**：真实时薪（元/h），1 秒 ease-out 数字滚动动效，营造"仪式感"。
2. **类型标签**（6 档，中文段位 + 英文副标题 + 毒舌文案）：
   - <20 元 → 纯种牛马 Purebred Niuma（"你的每一个毛孔都流淌着纯正的牛马基因…建议直接申请加入《动物世界》拍摄"）
   - <40 → 极品耗材 Premium Consumable
   - <80 → 觉醒牛马 Awakened Niuma
   - <150 → 摸鱼艺术家 Slacking Artist
   - ≥150 → 职场神仙 Workplace Deity
3. **矛盾信号覆盖（4 条 override 规则，本报告第二借鉴点）**——基础档之上，跨维度交叉判定：
   - 高基本盘 + 低时薪 → **落难贵族**（"不是你的问题，是这破岗位配不上你，立刻刷新简历"）
   - 高时薪 + 低环境分 → **镶金边的耗材**（"高薪本质是老板预支的【精神损失费】和【医疗费】"）
   - 低基本盘 + 高时薪 + 高环境分 → **风口上的天选之子**（"建议情绪稳定，死死抱住公司大腿"）
   - 低基本盘 + 低待遇 → **菜鸡互啄的稳定态**（"先苟住发育，把核心技能练出来再谈掀桌子"）
4. **五维雷达图**（Chart.js）：薪酬购买力/时间掌控权/情绪健康度/简历含金量/技能成长率 + 1–5 星性价比评分。
5. **成分拆解**：4 张卡片逐维给规则模板文本（通勤地狱度/城市生存难度/成长潜力分析/个人身价评估），如"在北上广深，这叫『跨省上班』…建议把地铁通勤时间算进工时"。
6. **行动按钮 + 免责**："换个姿势重测"、"仅供娱乐，请勿将测试结果发送给老板"。

**呈现结构总结：核心数字 → 类型标签 → 维度雷达 → 单维拆解 → 行动建议。** 这正是"结论-解释-建议"三层结构，与 TalentForge 画像层输出结构同构。

## 6. 对 TalentForge 画像层的借鉴点与排除点

### 可借鉴（手法层）

| # | 手法 | 出处 | 画像层落点 |
|---|---|---|---|
| 1 | **情境锚定选项（behavioral anchoring）**：选项 = 具体情境 + 第一人称独白（"我走了，公司交接至少得一个月"），而非抽象形容词 | 护城河题 | M1/M3 提问时，把人格/动机构念翻译成"可对号入座的生活化情境"，降低自我报告偏差与防御 |
| 2 | **矛盾信号覆盖判定（override rules）**：基础分型之上，用跨维度交叉（高基本盘×低待遇 → 落难贵族）识别"倒挂/错配" | 暴击场景 4 规则 | 三轨画像交叉印证：叙事轨（自述）与效用轨（硬数据）信号冲突时，优先输出"错配假设"而非合并平均 |
| 3 | **测量口径副文案**：选项下方用一行小字界定口径（"含隐形加班""含等车发呆"） | Step1 | 画像数据采集时给每个字段定义边界，保证证据链条目可解释 |
| 4 | **抗防御措辞**：placeholder"别不好意思写，没人看"、校验提示"哪怕是编的！" | Step1 | 提问式交互中用幽默/低威胁措辞降低粉饰作答（社会赞许性偏差） |
| 5 | **三轨输入结构**：客观数值（生存）→ 环境评价 → 自我定位，按"越客观越靠前"排序 | 三步流程 | 画像采集顺序：硬事实先行、主观自评殿后，减少锚定污染 |
| 6 | **结果呈现分层**：数字 → 标签 → 维度 → 拆解 → 建议 | 结果页 | 画像输出结构模板（可复用其信息架构，不复制其数值体系） |

### 不可借鉴（与约束冲突，需反向设计）

1. **基数打分与乘法权重 → 违反"序数偏好优先于基数打分"**。该测试把一切折成精确到 0.1 元的时薪，制造虚假精确。画像层应输出序数/偏好结构（"A 优于 B 的证据链"），而非"你值 42.7 分"。
2. **输入即答案 → 违反"证据链可回溯"的精神**。用户选了什么直接进公式，无交叉验证、无一致性检查、无置信度。画像层必须有证据来源标注与矛盾标记。
3. **确定性定论 → 违反"提问式非灌输"**。"老板正在疯狂白嫖你的剩余价值""立刻刷新简历"是替用户下结论的断言式输出。画像层应输出假设 + 证据 + 追问，把结论权留给用户。
4. **选项内嵌价值判断 → 引导性**。"😇 情绪稳定愿意教东西"天然优于"👹 PUA大师"，用户被推向"正确选项"。画像层选项必须保持构念中性（如迫选 A/B 都无对错）。
5. **无构念基础 → 维度不可借鉴**。五维（薪酬/时间/情绪/简历/成长）是拍脑袋拆解，无心理学依据。画像层的人格/动机维度须有构念来源（精神分析式读人的结构化框架），不能学其"看起来合理就行"。
6. **标签娱乐化 → 不可用于决策**。"纯种牛马/职场神仙"是情绪消费型命名，无可操作性。画像层标签需可反驳、可操作（附证据链），并允许用户否决。

## 7. 结论

- 该测评是**前端内联的娱乐计算器**，非心理测评；人格/动机/职业倾向类量表内容（迫选题、李克特、维度常模）在其中**不存在**。
- 对"读人"层真正有价值的是两件武器：**情境锚定选项写法**（降低自我报告偏差）与**矛盾信号覆盖判定**（跨维度错配识别）——前者进 M1/M3 的提问设计，后者进三轨画像的交叉印证逻辑。
- 其基数加权、断言式定论、无追溯设计被列为**反面清单**，写入本报告供提示词设计时显式规避。
