## 5. 关于"国际化企业/外企"的特殊处理说明

### 5.1 为什么外企不在默认企业类型里？

Step 0 的四类分法（互联网大厂 / 中型成长期 / 垂直行业龙头 / 传统行业）的核心逻辑是**业务相似性**——同类型企业的岗位能力要求相近，可以互相对标。

**外企的特殊性在于**：跨国企业的胜任力标准往往是**全球统一的框架**，在中国只是执行层，而非框架制定层。具体表现：

| 维度 | 中国本土企业 | 外资/跨国企业 |
|-----|-----------|------------|
| 能力标准制定 | 中国本地HR独立决策 | 总部全球统一，中高低差异大 |
| 行为指标来源 | 互联网/本土文化语境 | 全球胜任力模型（如IBM Leadership Framework、Mercer框架） |
| 绩效管理方式 | OKR/KPI混用，灵活 | MBO/PBC等西方体系，较规范 |
| 职业发展路径 | 快速晋升/轮岗 | 阶梯式晋升，培训体系成熟 |
| 能力评估文化 | 结果导向强，过程看情况 | 过程合规重要，文档化要求高 |

### 5.2 正确使用方式

**外企应该被当作"第五种类型"单独处理**，不是替代现有四类，而是补充。具体建议：

1. **不混用**：如果验证公司中包含外企，需要在 Step 0 单独标注「跨国企业/外企」，因为其胜任力逻辑与本土企业有本质差异
2. **单独建模层**：可以单独建立「外企胜任力维度」，与本土维度并列
3. **对比分析**：跨国企业更强调「跨文化协作」「合规意识」「英语书面能力」「全球视野」，这些在本土互联网大厂几乎不提
4. **适用场景**：高端人才引进（管理岗、专业技术岗），或需要对接全球标准的企业

### 5.3 为什么不把外企列为第五类默认类型？

**框架的初始设计目标是服务中国本土企业的HR场景**，包括：
- 招聘筛选（面向本土候选人）
- 内部晋升评估（本土组织文化）
- 培训规划（基于本土业务需求）

在外企工作的候选人，其胜任力模型本质上是"全球胜任力框架 + 中国本地执行"的叠加，如果用纯本土框架去套，会产生系统性偏差。因此建议：**当候选人有外企背景时，主动在 Q5 验证公司选择中注明"包含跨国企业"，并在 D3 行业维度中单独处理。**
